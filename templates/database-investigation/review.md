# Database investigation review

## Scope and baseline

Identify the selected run, source baseline or connected target, product/version, visible scope,
collection time and gaps. Use the configured output language throughout the report. For live
investigation set the frontmatter skill to investigate-db-live.

## Findings

For each finding, state the observed/declarative evidence, interpretation, impact, confidence
and bounded follow-up. Reference inventory evidence IDs or file/hash/line evidence for additional
design documents. Label inferred relationships and unproven performance concerns explicitly.

## Coverage and limitations

Explain unsupported syntax, withheld definitions, missing privileges, disabled metrics,
timeouts, truncation and unknown measurement/reset times. Preserve partial status.

## Open decisions

Reference OQ IDs in the shared work/context.md; do not establish a separate question store.
